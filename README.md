# Cosyclick Website

Multi-page static website structured for GitHub and Hostinger.

## Pages
- index.html
- about.html
- services.html
- lead-generation.html
- paid-media.html
- email-marketing.html
- industries.html
- case-studies.html
- contact.html

## Folders
- css/style.css
- js/script.js
- assets/images/

## Before publishing
1. Replace `hello@cosyclick.com` with your real email.
2. Replace `919999999999` in WhatsApp links with your actual WhatsApp number.
3. Replace sample statistics and case-study metrics with real, verifiable results.
4. Add your logo/images under `assets/images/` if needed.
5. Update the domain/branding as required.

## GitHub
Create a repository, copy these files into it, commit and push.

## Hostinger
Upload the repository contents to `public_html`, or connect the Git repository through Hostinger's Git deployment feature if available on your plan. The `index.html` file must be in the web root.

## Important
The contact form is front-end only and opens the visitor's email application. For direct submissions without an email client, connect it to a form service or backend.
